Daily Hiku on your site.

Norsk · English · Svenska · Dansk · Suomi · Deutsch

Daily Hiku is a calm number puzzle with four new boards every day, from easy to expert. It is free to embed on a news site or any web page, with two lines of code.

The rule is short: the number says how far it jumps, across or up and down. When it lands on another number, the smaller is taken from the larger. The goal is to make every number disappear. The boards are the same as in the Hiku app for iPhone.

How to do it

  1. Paste the code below where the game should appear, for example in an article or on a puzzle page of its own.
  2. Publish. The game fetches today's boards itself and adjusts its height.
HTML
<div data-hiku data-lang="en"></div>
<script src="https://hikupuzzle.com/daily/embed.js" async></script>

The script only needs to appear once per page, even with several games on the same page.

Try and copy

Pick the settings, watch the game change, and copy the code when you are happy with it.

Code

Options

Options are set as attributes on <div data-hiku>.

AttributeValuesWhat it does
data-langnb, en, sv, da, fi, deThe game's language: Norwegian, English, Swedish, Danish, Finnish or German. Without it, the language of the surrounding page (<html lang="…">) is used, and otherwise Norwegian.
data-themelight, darkFixes the colours. Without it, the game follows the reader's light or dark mode.
data-alignleftPuts the game at the left. Without it, the game is centred in the space it is given, and is never wider than 480 pixels.
data-leveleasy, medium, hard, expertWhich of today's four boards is shown first. Without it, the game opens on the level the reader played last, and otherwise on Easy. The reader can always switch.

Example, always light and with Medium first:

HTML
<div data-hiku data-lang="en" data-theme="light" data-level="medium"></div>
<script src="https://hikupuzzle.com/daily/embed.js" async></script>

Without script

If your publishing system does not allow scripts, embed the game as a plain iframe. Its height then does not adjust itself, so set it. 860 pixels fits the whole game, including a solved board; the game is never wider than 480 pixels.

HTML without script
<iframe src="https://hikupuzzle.com/daily/?lang=en"
  title="Daily Hiku" loading="lazy"
  style="display:block;width:100%;max-width:480px;height:860px;border:0;margin:0 auto"></iframe>

Options then go in the address: ?lang=sv, &theme=dark, &level=hard. The position is set by the frame's style; remove margin:0 auto to put it at the left.

Privacy and operation

  • No cookies and no tracking. No game data or results are sent to us. Results and stars are stored only in the reader's own browser. The App Store link carries the name of the site the game is on, so we can see in App Store Connect how many came from each site in total. Only Apple receives it, and only if the reader follows the link. The host receives ordinary technical requests when the files load, as with any web page.
  • An isolated game. The game itself runs in an iframe from another address and cannot read or affect the page around it. The small loader script, embed.js, runs on your page like any other external script: it creates the frame and sets its height, and does nothing else. Its source is short and can be read at embed.js. Newsrooms that do not allow external scripts use the iframe version.
  • Light. The first load is about 70 kB compressed. The frame only loads as the reader approaches it.
  • New boards at midnight in the reader's time zone. The library lasts three years, and the boards are the same as in the app.
  • Hosted on Cloudflare. The host sees the reader's IP address when the files load, as with any web page.

For technical teams

Recommended for strict security requirements

Use the iframe version above. Then no code of ours runs on your page, only inside the frame. All you lose is the automatic height.

Content Security Policy

With the loader script both are needed; with a plain iframe only the second:

CSP
script-src https://hikupuzzle.com;
frame-src https://hikupuzzle.com;

Add them to your existing directives. The game in the frame only loads files from the same address.

Stability

  • The addresses …/daily/embed.js and …/daily/, and the attributes in the table above, will stay. New options are added without changing existing ones.
  • The script loads with async and never holds up the rest of the page.
  • If Cloudflare is unavailable, the space where the game would be stays empty. The page around it is not affected.
